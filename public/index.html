Try a scenario

      
Send a normal alert, or follow a short guide through a failure and its recovery. Guides never start by
         themselves, and each step waits for what the sandbox actually reports.

      

      
Normal delivery
The receiver works normally. Send one alert and follow it from start to finish.
Sets the receiver back to "Works normally" if needed, then sends one alert.
Recover from a temporary problem
The receiver rejects the first try. You restore it, and a scheduled retry succeeds.
Sets your receiver to "Temporary outage" for the whole session, then sends one alert. One step at a time.
Avoid processing twice
The receiver processes the alert but replies too late. A retry is recognized as the same alert.
Sets your receiver to "Processes, then replies late" for the whole session, then sends one alert. One step at a time.
Rescue a stopped delivery
Every automatic try fails. You restore the receiver and retry the delivery by hand.
Sets your receiver to "Temporary outage" for the whole session, then sends one alert. One step at a time.

        How the demo session token is stored
        
Starting a session gives this tab an anonymous token that expires after 24 hours. It is kept in this tab's
           sessionStorage: it survives a reload, disappears when the tab closes, and is never put in a URL
           or shown on the page. Any script running on this page could read it, which is acceptable for a throwaway demo
           credential with no personal data, but not for real accounts (those would use HttpOnly cookies).
           The page loads only its own scripts and never inserts received text as HTML.
