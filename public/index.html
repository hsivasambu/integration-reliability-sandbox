How the demo token is stored

Starting a session gives this tab an anonymous token that expires after 24 hours. It is kept in this tab's sessionStorage: it survives a reload, disappears when the tab closes, and is never put in a URL. Any script running on this page could read it, which is acceptable for a throwaway demo credential with no personal data, but not for real accounts (those would use HttpOnly cookies). The page only loads its own scripts and never inserts received text as HTML.
